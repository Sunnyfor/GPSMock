一、视觉样式
────────────────────────────────────────
采用标准 KDoc + 中文语义标题，在 Android Studio 源码与快速文档中均可阅读。

类级注释：一句话概述 → 按需分节，说明整体职责、整体不变量与使用边界。
方法注释：行为概述 → 必要的执行规则 → 有信息价值的参数、返回值和异常说明。
字段注释：KDoc 紧贴成员声明上方，说明含义、单位、取值与可空语义，链接相关行为。
构造函数属性：同样直接在 val/var 声明上方写 KDoc，不在类注释中集中罗列。
枚举注释：类型级说明状态权威，每个取值单独解释含义。
行内注释：说明实现原因、操作顺序及隐藏风险。

仅在复杂类确有分组需要时使用轻量分隔线，例如：
    // ── 业务行为 ──────────────────────────

不使用大幅字符画边框、表情图标、需要对齐的中文表格或无事实依据的作者/日期栏。
标准 KDoc、空行和清晰命名构成主要层次。简单类不添加分隔线，不为每个类型套满章节。

信息分工：每条规则有一个主要说明位置；其他位置用短摘要与真实符号链接保持局部可读。
整体不变量属于类；属性含义与取值属于成员；操作条件、重复语义和失败结果属于方法。
值对象的约束由值对象说明，引用它的成员不再复制完整规则。
新增约束时同步更新主要说明位置和相关测试，不在多个位置复制长段说明。

二、类级模板
────────────────────────────────────────
/**
 * <中文业务名称>：<一句话说明职责>。
 *
 * ## 领域职责
 * <整体职责及规则入口，使用真实符号链接关联创建、修改或恢复行为>。
 *
 * ## 使用边界
 * <当前实现提供什么保证，调用方承担什么责任>。
 */

若存在跨多个行为共同成立的整体不变量，可按需增加“核心规则”，不重复方法细节。
值对象只在确有细节时增加“长度语义”“坐标语义”；技术类按需说明“计算规则”。
章节名称服务于实际内容，不要求领域类、技术类或简单类型使用相同章节。

三、成员模板
────────────────────────────────────────
    /**
     * 当前修订版本，用于识别收藏内容的修订状态，必须为正数。
     *
     * 初始值见 [create]，修改规则见 [revise]；恢复时保留快照中的版本。
     */
    var revision: Long = revision
        private set

简单成员、快照字段和枚举取值使用一行 KDoc 即可；有单位、可空含义、参考系、
失效条件或特殊取值的成员才详细展开。说明完整性优先，不以注释长度衡量质量。
成员之间保留空行；已有 val/private set 等可见语法不机械翻译，需要时说明业务原因。
本项目默认使用就地成员注释；@property 仅在确有集中 API 文档需求时单独评估，
并保持同一属性的一处说明来源。私有构造函数的同名入参无需再次机械复制成员文档。

构造说明只补充初始化特有信息：输入规范化、转换、防御性复制、参数关联约束、
非成员参数、初始化副作用、异常和调用方责任。简单赋值且无附加契约时无需单独构造文档。
主构造契约可放在类型文档；通过 create/restore/of 构造时集中在真实入口，不重复成员含义。

四、方法模板
────────────────────────────────────────
/**
 * <用中文说明业务动作或技术行为>。
 *
 * ## 执行规则
 * - <真实适用的条件、成功结果、重复调用或失败状态；简单方法省略分节>。
 *
 * @param <参数名> <业务含义与调用方责任>。
 * @return <返回结果含义；没有返回值时省略>。
 * @throws <真实异常类型> <准确触发条件与失败后状态>。
 */

标签按需使用。参数需要解释单位、语义差异或调用方责任时使用 @param；
返回值存在易混淆的状态、空值或结果语义时使用 @return；Unit 方法省略 @return。
仅记录真实异常与触发条件。不要为了填满模板重复方法概述或显而易见的参数名称。
KDoc 使用真实符号链接，例如 [revise]、[Long.MAX_VALUE]；说明代码而不更改 API 名称。

行为样例：
    /**
     * 修改收藏内容，并推进一次修订版本。
     *
     * ## 执行规则
     * - 名称和完整坐标整体替换，收藏身份保持不变。
     * - 即使传入值与当前内容相同，成功调用也会递增版本。
     * - 版本检查先于属性修改；失败时名称、坐标和版本均保持原值。
     *
     * @throws IllegalStateException 当前版本已达到 [Long.MAX_VALUE]。
     */

五、说明深度
────────────────────────────────────────
详细说明优先回答“为什么”和“边界是什么”，而不是逐行翻译赋值语句。
涉及坐标、时间、像素/密度、版本、代次时，说明单位、参考系与比较语义。
涉及异步状态时，区分请求意图、执行事实与最终确认；说明旧回调和重复动作。
涉及存储/清理/并发时，明确当前保证与调用方责任，避免承诺尚未实现的全局能力。
未来建设计划与适配方案放架构文档；注释只保留当前理解或正确调用所必需的边界信息。
时间字段说明单位与时钟来源；坐标说明参考系；可空字段说明 null 含义；
异步身份说明旧回调失效条件。内容按实际模型选择，不机械加入无关小节。
行内注释只补充 KDoc 未覆盖的实现动机，不重复显而易见的语句或方法规则。
注释仅改变说明文本；异常消息、业务语义与运行行为保持不变。
测试注释说明业务场景、输入边界与预期结果，不重复每个断言的代码。
新增规则时同步维护相关注释，避免文档承诺超出代码与测试证据。
