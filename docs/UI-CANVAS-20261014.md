# 地图画布实施记录

日期：2026-10-14。用户选择地图画布结构，随后要求精简隐私弹窗、独立阅读全文并撤掉绿色主辅配色。
当前为靛蓝行动色、中性白灰容器及配对深色令牌；原型仅在本地，未提交、不作为 Android 资源。

## 界面与适配

`CanvasPositionScreen` 替代旧 Atlas 页面；无重复底部导航。搜索悬浮在真实地图顶部，居中入口离开底部版权区；不伪造地图或覆盖高德 Logo/版权。摘要仅展示目标和必要状态，坐标/搜索/设置按需展开，收藏管理保留原有 CRUD。

安全区由 Activity 同一 surface 绘制，系统图标随明暗同步，不再由 Scaffold 绘制另一种容器色。
窄窗沿用实际容器像素宽度 / 360 的局部设计密度；地图弹性占据余量，摘要有容器高度比例上限并可滚动，主按钮不进入滚动区。宽窗显式左右布局；原生地图恢复系统密度，系统字体缩放仍保留。

首次隐私确认只显示用途摘要、全文入口和明确选择。`PrivacyNoticeReader` 是独立阅读页：固定返回、限宽正文、章节编号和间距，不显示同意按钮；返回阅读页不等于同意。开发者与联系字段用简短中文占位，集中在 `app/src/main/res/values/privacy_config.xml`；搜索 `PRIVACY_PLACEHOLDER` 可定位配置注释。正式发布前须替换，当前说明不是法律意见或合规认证。

## 隐私记录

`platform.ui.privacy` 记录 App 告知版本、高德政策版本、地图同意、定位用途选择及时间，不保存设备标识或坐标来证明点击。
匹配当前版本且明确同意后恢复在线意愿，同版不重复弹政策；拒绝也记录，用户主动重新开启时可再选择。定位用途的拒绝单独记忆，不在每次冷启动重问。

撤回先关闭内存门禁并取消请求，再记录拒绝；保存失败给出提示，不宣称已持久撤回。关闭在线不等同撤回；已有网络请求不能撤销，旧回调被忽略。SharedPreferences 由现有两个备份 XML 规则排除云备份和设备迁移，仍需实际 OEM 恢复验证。发版前核对高德政策更新并维护版本常量/告知内容，不承诺静态版本永久有效。

## 一次设备定位

`DeviceLocationClient` / `AndroidDeviceLocationAdapter` 位于 UI 平台层，使用现有 AndroidX 系统接口，不增加第三方依赖或业务 BC，不初始化高德定位客户端。生产仅新增 FINE/COARSE 前台权限，不申请后台定位。

门禁包含在线服务同意、定位用途同意及当前系统权限。首次用途同意后按需申请；以后仅在权限有效且未选择目标时自动尝试一次，否则保留主动居中/系统设置入口。大致位置使用更宽视野；超时、拒绝或系统服务未开启时保持选点/手输可用。

单次最多等待 12 秒；mock、超过 30 秒、无效经纬度/精度的结果拒绝。成功、取消和超时释放系统请求。后台、选点、关闭在线、撤回、模拟启动及非 Idle 会话状态均使请求失效；协程取消继续传播，迟到结果不得抢占目标。

定位只形成 WGS-84 相机意图，高德绘制时单向转换；不会自动创建 selected、查询其地址、收藏或启动模拟。不显示设备精确坐标，不建立轨迹，不宣称运行中可以取得真实位置。
